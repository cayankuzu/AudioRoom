# Yazı tipleri

Tüm dosyalar SIL Open Font License 1.1 (OFL) lisanslı Google Fonts ailelerinden
alınmış, Türkçe dahil Latin karakter setine göre alt kümelenmiştir
(`fontTools.subset`). `.woff2` dosyaları arayüz CSS'i içindir. 3D hacimli yazılar
için `assets-src/fonts/*.ttf` kaynakları `npm run fonts` ile `*.typeface.json`
biçimine çevrilir (three `FontLoader` + ekstrüzyon).

| Dosya | Aile | Kullanım |
|---|---|---|
| manrope-400/600/800.woff2 | Manrope | Arayüz metni |
| plex-mono-500.woff2 | IBM Plex Mono | Etiketler, tuş simgeleri |
| cinzel-400 | Cinzel | Redd · Mükemmel Boşluk başlıkları |
| sedgwick-400 | Sedgwick Ave Display | Hayko Cepkin · Beni Büyüten Şarkılar başlıkları |
| cormorant-500 | Cormorant Garamond | Henry the Lee · Kuantum Dolanıklık başlıkları |
| courier-prime-400/700 | Courier Prime | Henry the Lee · Klostrofobik Kaplumbağa başlıkları |

Lisans metni: https://openfontlicense.org
